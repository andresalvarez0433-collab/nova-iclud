# NovaCloud Gaming

Proyecto Android inicial para generar una APK de prueba mediante GitHub Actions.

## Compilar
1. Abrí la pestaña **Actions**.
2. Seleccioná **Crear APK de NovaCloud Gaming**.
3. Pulsá **Run workflow**.
4. Cuando termine correctamente, descargá el artefacto **NovaCloud-Gaming-1.0-debug-apk**.
5. Extraé el ZIP y transferí `app-debug.apk` al teléfono para instalarlo.

Esta es una APK debug para pruebas, no una versión firmada para distribución pública. La app abre Xbox Cloud Gaming en el navegador externo; no implementa streaming integrado ni cambio real de región.
