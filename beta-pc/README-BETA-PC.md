# NovaCloud Gaming — PC Beta 0.5.0

Archivo principal: [NovaCloud-PC-Beta-0.5.0.user.js](./NovaCloud-PC-Beta-0.5.0.user.js)

## Instalación
1. Instala Tampermonkey en Chrome o Edge.
2. Abre el archivo .user.js desde GitHub y pulsa **Raw**; Tampermonkey debería ofrecer instalarlo.
3. Abre https://www.xbox.com/play y recarga.

## Estado real de esta beta
Es un prototipo experimental con panel, preferencia regional local, detección básica de entrada y contadores manuales.
**No implementa todavía el cambio real del servidor/región de Xbox, ni altera FPS/resolución/bitrate, ni detecta automáticamente cofres o eliminaciones.** El botón de región solo guarda la preferencia y recarga la página. No se ha validado el inicio de Fortnite.

Para descargar el repositorio: botón **Code → Download ZIP**.
